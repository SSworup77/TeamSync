## Team Sync
A web application that could be used in professional setting where teams and projects can be easily managed in a personal windows termed as 'Workspace' and each workspace as a unique invitation code where usually the team-lead or the manager can invite the team members to introduce them with the project and the workspace. The manager/team lead could communicate the task with the team and assign the task and track them accordingly. The UI/UX is professional ensuring productivity isn't halted.

### Week 1 - Designing the UI🎨
Starting with the project I want to look into the UI of various team management applications and dashboard that ensures accessibility of the users and increases productivity all the while making it simple and minimalistic.
